# Ebun Platform

Ebun is a digital gifting platform for Nigeria and the Nigerian diaspora.

## Repository structure

- `apps/marketing` — public marketing website (To Be Added)
- `apps/web` — Ebun product web app
- `apps/api` — NestJS API and business logic
- `packages/ui` — shared UI components
- `packages/types` — shared TypeScript contracts
- `packages/config` — shared configuration
- `supabase` — database migrations and local Supabase configuration

## Architecture

Next.js → NestJS → Supabase/PostgreSQL

## Current stage

Pre-launch / MVP development.
